# Материалы

Каталог: course.json. Сейчас готовы основной пакет js-01 и его короткая вариация js-01-r1; остальные уроки обозначают план.

Открывай lesson.md для ученика. exercises.json содержит данные для будущего интерфейса и ожидаемые результаты для проверки. Решения и ожидаемые выводы трассировки не показывать до попытки или прямой просьбы.

Вариации той же основы лежат в `reinforcements/`. Они заменяют неотвеченное задание, а не создают учебный долг. Их ID и revision сохраняются вместе с попыткой.

Проверка из корня: `node scripts/validate-content.mjs`. Зависимости npm не нужны.
