# Урок 01. Значения, выражения и переменные

Цель: объяснить, какое значение получается при вычислении и что меняет присваивание. На урок и обязательную задачу — 25–35 минут. Ранее изученные темы не предполагаются.

**Значение** — конкретные данные, например число `8`. **Литерал** — запись значения в коде: `8`. **Выражение** — код, вычисление которого даёт значение: `count + 2`. **Переменная** — именованная привязка к значению.

`let` объявляет переменную. Начальное значение задаётся при инициализации. Последующее присваивание меняет значение существующей изменяемой переменной. Главное правило: в простом присваивании сначала получаем значение правой части, затем сохраняем результат слева.

```js
"use strict";

let apples = 3;
let saved = apples;
apples = apples + 2;
console.log(apples, saved); // 5 3
```

При инициализации `saved` читается текущее число `3`. Следующая строка вычисляет `3 + 2` и присваивает результат `apples`. Переменная `saved` продолжает обозначать `3`: выражение не сохраняется как автоматически обновляемая формула.

Это объяснение поведения языка, а не схема памяти V8. В примере только числа: меняются привязки, мутации объектов нет. `console.log` — готовый инструмент вывода; его устройство изучим позже.

**Задача A — прогноз до запуска.**

Среда для всех фрагментов: Node.js, обычный файл `practice.js`, строгий режим задаётся первой строкой. Запуск: `node practice.js`.

```js
"use strict";

let score = 6;
let bonus = score + 2;
score = 1;
console.log(score, bonus);
```

Вход — начальные числа в коде. Выход — пара чисел в консоли. Выпиши значения переменных после каждой строки и прогноз вывода. Затем запусти и объясни совпадение или расхождение.

Три независимые проверки: исходный код; замени только `score = 1` на `score = 0`; в исходном коде добавь `bonus = score + 2` перед выводом. Для каждой начни с исходных объявлений. Ответы заранее не приводятся: здесь проверяется именно прогноз.

**Задача B — по желанию.** В расширенном режиме 75–100 минут оставшееся время отведи практике и объяснению без конспекта. Заданы `hours` и `minutes` — целые числа: 0–24 и 0–59 соответственно. Создай `totalMinutes` и выведи общую длительность. `*` — умножение, `+` — сложение. Исходные переменные не изменяй; функции не нужны.

Проверки: `(2, 15) → 135`, `(0, 0) → 0`, `(1, 59) → 119`.

Типичная ловушка: ожидать автоматического пересчёта `bonus` после изменения `score`.

Вопрос собеседования: чем отличаются объявление, инициализация и последующее присваивание?

Ответ: прогноз → код → объяснение → фактический запуск → использованные подсказки. В первом уроке вопросов на повторение ещё нет.
