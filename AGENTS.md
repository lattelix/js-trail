# Инструкция исполнителю

Читай README.md, docs/context.md, docs/content-contract.md, docs/roadmap.md и docs/curriculum.md (нужную тему). Ответы владельцу — на русском.

Этот репозиторий публичный. Храни здесь общий учебный контент и контекст продукта. Личные ответы, оценки, интервью, журнал и данные приватного vault сюда не копировать. Их источник передаётся в приватном контексте сессии; при отсутствии доступа честно сообщить ограничение.

Сначала определения и один механизм, затем другой разобранный пример, прогноз до запуска и самостоятельная задача. Полное решение в ученическом выводе — после попытки или прямой просьбы. Выдача не равна освоению. Не выдумывать результаты и не повышать сложность по календарю. Неизвестную самостоятельность не оценивать баллами.

Редактируя урок, обновляй revision и связанный каталог; при существенном изменении задачи сохраняй прежние попытки привязанными к прежнему commit. После реального ответа обновляй приватный журнал. Все источники проверяй при использовании, историческую дату проверки не выдавай за сегодняшнюю.

После изменения контента запускай node scripts/validate-content.mjs. Проверки исполняют только доверенные авторские примеры, НЕ код ученика. Не использовать node:vm как безопасную песочницу для чужого кода.

Работай с текущими SHA, без force push. Изменения двух репозиториев не атомарны: проверяй каждую запись и сообщай частичный сбой. Не отмечай урок delivered/completed по одному commit. Разработка UI, выбор облака, авторизация и деплой не входят в текущий этап подготовки материалов.
