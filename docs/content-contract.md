# Контракт контента v1

Учебный контент каноничен в этом репозитории; личные попытки и оценки — в приватном журнале. В журнале сохраняется снимок выданного текста, lesson_id, task_id, revision и commit. Смена версии не изменяет старую попытку.

content/course.json: schema_version, course_id, version, language, progression, lessons. У каждой записи lesson_id, title, status, prerequisites. Для prepared обязательны revision, lesson_path, exercises_path. planned не означает готовый урок.

lesson.md: lesson_id/version/status/language в frontmatter; цель, термины, механизм, другой разобранный пример, практика, среда, ограничения и вопрос интервью. Обычно 250–450 слов плюс код. 25–35 минут базовый режим; 75–100 расширенный по желанию.

exercises.json: schema_version, lesson_id, revision, environment, tasks. У задачи task_id, kind, required, prompt, constraints, answer_format, starter_code, checks, feedback_visibility, hints и rubric. Поддержаны trace/code в js-01. Поля должны быть согласованы с текстом.

checks содержит авторские ожидаемые результаты. Для trace интерфейс скрывает их до попытки или просьбы. Публичность репозитория означает, что читатель исходников может их увидеть; это не секретные тесты. Отдельный файл solutions.md добавлять только при подготовке развёрнутого разбора, не показывать автоматически в ученическом экране.

Проверки: обычный вход, край и вариант, отличающий правильное правило от ошибочной гипотезы. Результат запуска не заменяет доказательство и объяснение. Локальные скрипты предназначены только для доверенного авторского кода, не для приёма кода через сеть.

Прогресс: prepared → delivered → attempted → reviewed → needs_review/provisionally_passed → consolidated. События не выводятся одно из другого автоматически. Пять осей 0–2: корректность, понимание, края, самостоятельность, ясность/сложность. Unknown не превращать в 0. От 8/10 без критической ошибки — предварительный результат; закрепление после изменённой задачи позднее. Повторы примерно 1/3/7/14 дней — эвристика.

После изменения контента: проверить, сохранить commit приложения; затем записать ссылки и соответствующий факт в приватном журнале. При частичном сбое не заявлять синхронизацию. Автоматического обмена пока нет. Полный приватный vault, персональная диагностика и ответы не переносятся в этот репозиторий.
