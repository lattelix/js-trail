# Продукт

JS Trail помогает понять поведение JavaScript, объяснить прогноз, решить задачу и вернуться к слабому месту. Первичная аудитория — начинающий frontend-разработчик.

Будущий минимальный сценарий: урок → прогноз → код/ответ → проверка → объяснение → повторение → история. Основной кандидат интерфейса — адаптивный web; native iOS/macOS отдельно не планируются до подтверждённой необходимости. Это направление, не выбранный стек.

Полезные функции: ступени подсказок, неизменённая история попыток, крайние случаи, карта проверенных навыков, экспорт данных. Пропущенные дни не создают долг и не обнуляют знания. Серия входов и просмотр уроков не считаются освоением.

Вход и синхронизация между устройствами — будущие требования. Первая реализация должна отдельно решить изоляцию выполнения, таймауты, хранение персональных данных, безопасный DOM и доступность. Автоматическая проверка не заменяет разбор объяснения.

Методика: извлечение из памяти, распределённая практика, чередование примера и самостоятельной задачи, обратная связь. Источники и ограничения — docs/curriculum.md. Самодельное приложение не имеет доказанного превосходства над занятиями с наставником.
